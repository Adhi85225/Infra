## Project tracking

Kept at the repository root:

- [PRIORITY.md](../PRIORITY.md) — the prioritised development roadmap.
- [PROJECT_STATUS.md](../PROJECT_STATUS.md) — what is happening right now.
- [CHANGELOG.md](../CHANGELOG.md) — meaningful changes.

## Keeping documentation honest

These files are part of the deliverable, not an afterthought:

1. Update documentation **in the same change** as the code it describes.
2. Never mark something complete that is not implemented and verified.
3. When a design decision changes, update the decision record in
   [PROJECT_STATUS.md](../PROJECT_STATUS.md) — including why.
